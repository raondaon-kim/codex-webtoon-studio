# 말풍선 56종 로컬 분석

이 폴더는 사용자가 제공한 `webtoon_studio/말풍선 56종 png.zip`을 풀어 정식
레터링 자산으로 편입한 사본이다. 프로젝트 소유자는 제작자인 지인으로부터 MIT
배포 허락을 받았음을 확인했다. 상세 표기와 라이선스 전문은
[`PROVENANCE.md`](PROVENANCE.md), [`LICENSE`](LICENSE)에 있다.

아래 분류는 실제 PNG를 선택할 때와 말풍선 엔진을 확장할 때 모두 쓰는 **형태의
기능**을 기록한다.

## 인벤토리

- 개별 자산: `말풍선 (1).png`부터 `말풍선 (56).png`까지 56개
- 스프라이트/미리보기: `(57)`, `(58)`, `말풍선001`, `말풍선002` 4개
- 안내 JPG: 1개
- 전체: PNG 60개 + JPG 1개. PNG 58개는 투명 배경을 가진다.
- 개별 자산의 표준 캔버스는 대체로 약 `789 × 703px`이다. 꼬리와 외곽선이
  이미 고정된 래스터라, 화면 속 화자 위치에 맞춰 꼬리를 회전·연장하기 어렵다.

시각 확인용 파일:

- `contact-sheet.png`: 흰 배경에서 보는 전체 모양
- `contact-sheet-checker.png`: 흰색/반투명 외곽을 식별하는 체크 배경 버전

## 우리 엔진에 남길 원칙

1. 보통 대사는 현재의 깨끗한 타원과 화자-지향 곡선 꼬리를 유지한다.
2. 독백은 구름형 외곽과 3개의 점을 사용한다. 점의 방향은 화자의 머리를 향한다.
3. 외침에는 가시형, 충격 효과음에는 방사형을 **매개변수형 벡터**로 새로
   구현하는 방식을 우선한다. 라이선스가 확인된 이 패키지의 PNG는 특별 연출을
   위한 선택 자산으로 쓸 수 있다.
4. 고정 래스터 꼬리는 화자 위치·카메라 거리·말풍선 크기에 대응하지 못하므로,
   실제 컷 배치에 사용하지 않는다.
5. PNG를 선택할 때는 `asset-catalog.json`의 용도와 크롭 여백을 확인하고, 최종
   컷에서는 인물·독해 순서·꼬리 방향을 우선한다.
