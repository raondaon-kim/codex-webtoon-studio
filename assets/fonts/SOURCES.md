# Bundled lettering fonts

These files are bundled so deterministic lettering does not depend on a creator's
installed system fonts. Every font below is licensed under the SIL Open Font
License 1.1; its full text is in [OFL-1.1.txt](OFL-1.1.txt).

| Role | File | Upstream source |
| --- | --- | --- |
| Dialogue | `NanumGothic-Regular.ttf` | [Google Fonts: Nanum Gothic](https://github.com/google/fonts/tree/main/ofl/nanumgothic) |
| Caption | `NanumMyeongjo-Bold.ttf` | [Google Fonts: Nanum Myeongjo](https://github.com/google/fonts/tree/main/ofl/nanummyeongjo) |
| Thought | `NanumPenScript-Regular.ttf` | [Google Fonts: Nanum Pen Script](https://github.com/google/fonts/tree/main/ofl/nanumpenscript) |
| SFX | `NanumGothic-Bold.ttf` | [Google Fonts: Nanum Gothic](https://github.com/google/fonts/tree/main/ofl/nanumgothic) |

Do not replace a font with a similarly named system installation. Update the
profile and this table together when changing the house type system.
